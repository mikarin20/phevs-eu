# PHEVs.eu - PHEV Comparison Site

Europe's most comprehensive PHEV comparison platform.

## Features

- **PHEV Vehicle Comparison**: Compare up to 3 PHEV vehicles side by side
- **Advanced Filtering**: Filter by brand, price range, electric range, and fuel consumption
- **Real-time Search**: Search vehicles by brand or model name
- **Detailed Specifications**: Electric range, fuel consumption, battery capacity, power, CO₂ emissions
- **Modern UI**: Clean, responsive design with Tailwind CSS
- **Mobile Friendly**: Optimized for all device sizes

## Current Models

- **Peugeot 3008 Hybrid4 2025**: €42,900 - 59km electric range
- **Kia Sportage PHEV 2025**: €38,900 - 70km electric range

## Technology Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Heroicons
- **Deployment**: Vercel
- **Domain**: phevs.eu

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)
